# 喵筆記是使用Gemini製作的
## 介紹
&emsp;&emsp;本網站使用HyperText Markup Language(HTML)、JavaScript(JS)、Cascading Style Sheets(CSS)製作的，並且加入了PWA(漸進式網頁應用程式)，可以直接開啟，也可以安裝成:電腦版、手機版(備註:必須瀏覽器支援，基本上只要是Chrome的核心Chromium都可以)

## 功能特色
### 視圖分類
**所有筆記:**
顧名思義，就是全部的筆記(備註:除了垃圾桶之外)

**星號收藏:**
點擊最上方的星號，如果是實心的，那麼就會看到出現在星號收藏了(備註:除了垃圾桶裡面的之外)

**垃圾桶:**
點擊上方工具列的垃圾桶，就會將那個筆記放置到垃圾桶，且在垃圾桶的檔案，無法編輯，可還原
### 分類資料夾
**未分類:**
在所有筆記、星號收藏中點擊新增筆記出來的筆記，將會放置於未分類

**預設建立的:**
無法刪除，包含:「未分類、工作項目、個人想法、讀書筆記」

**自行建立的:**
可以刪除、自訂名稱(暫時不支援重新命名)，刪除:將滑鼠游標一至資料夾上方，右邊將顯示刪除(備註:手機版本請長按)
### 介面樣式
打開選單，找到最下的「深色模式」或「淺色模式」點下去即可更變深淺色樣式(備註:不支援自動更變)

## 編輯筆記
1. 本「CatNote 喵筆記」是使用Markdowm(md)
2. 支援多檢視模式

    2-1. 編輯，單純編輯

    2-2. 分頁，左邊為編輯，右邊為預覽

    2-3. 預覽，單純預覽 
3. 將寫好的檔案下載下來(備註:匯入，請在電腦、手機或平板，打開檔案，全選(Ctrl+A>複製(Ctrl+C)>回到CatNote 喵筆記，打開筆記>全選(Ctrl+A)>貼上(Ctrl+V)，匯入完成!
(備註:未來的版本將加入直接匯入功能)
